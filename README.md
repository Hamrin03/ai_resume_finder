# AI Resume Finder

## Project Overview
AI Resume Finder is a beginner-level Python project that demonstrates a simple ingestion pipeline and compares different chunking strategies for retrieving information from resume text.

## Objectives
- Understand a basic ingestion pipeline.
- Implement fixed-size chunking.
- Implement sentence-based chunking.
- Implement overlapping chunking.
- Compare retrieval results using keyword search.

## Chunking Strategies
1. Fixed-size chunking
2. Sentence-based chunking
3. Overlapping chunking

## Technologies Used
- Python
- Visual Studio Code

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Run the following command in the terminal:

python main.py

## Project File
- main.py — Contains the ingestion, chunking, and keyword search functions.
